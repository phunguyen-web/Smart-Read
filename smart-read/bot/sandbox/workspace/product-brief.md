# Smart-Read product brief

Web app to edit PDFs in the browser and convert them to other reading/editing formats.

## Must have

- Upload a PDF (max 20 MB), preview pages (stronger scale on small/sparse pages).
- Edit: thumbnail strip (strong contrast on sparse pages), multi-select rotate 90°/180°, reverse page order, interleave two halves (duplex scan) or split odd/even, 2-up / 4-up onto A4 sheets, saddle-stitch booklet impose (print-sheet preview), flip pages horizontally or vertically, split a page in half (top/bottom or left/right), rotate selected pages to portrait or landscape, scale pages by 50/75/125/150%, stamp page numbers, watermark, header/footer, cover page, page border, crop or add margins, unify mixed page sizes, reading tint, page background color, auto-crop whitespace, grayscale, find text (diacritic-insensitive), go to page, remove pages with no extracted text or with duplicate text, fit selected pages to A4, Letter, or A5, odd/even/invert select, delete/duplicate, extract selected pages as a new PDF, keep only the selection, split every N pages into a ZIP of PDFs, insert a blank page or PNG/JPEG/WEBP images, drag a selection as one block (or send it to start/end), undo/redo (persisted locally), merge at a chosen position, PDF title/author/subject, click-to-place text overlay (including top-right / bottom-center / bottom-right), redact a line/block/page band, highlight, underline, or strikeout a line/block/page band, outline bookmarks for selected pages (including dest-less nested folders (depth 3, per-folder collapse, rename/remove, move up/down, indent/outdent, retarget dest, named destinations including retarget/rename/duplicate/remove/clear/selection dests (`addNamedDestsForSelection` / `clearNamedDests`), XYZ/Fit/FitH/FitV/FitR/FitB/FitBH/FitBV views (`setNamedDestView`) and XYZ left/top/zoom, A4/Letter/A5 top-left presets, and dest-page top/top-right/bottom-left/bottom/bottom-right/left/center/right edges and XYZ zoom 50%/75%/100%/125%/150%/200%/fit-width/fit-height/fit-page/keep/keep-left/keep-top/zero-left/zero-top/origin/home/max-left/max-top/far/end/mid/focus/mid-left/mid-top/quarter-left/quarter-top/three-quarter-left/three-quarter-top/eighth-left/eighth-top/sixteenth-left/sixteenth-top/thirty-second-left/thirty-second-top/sixty-fourth-left/sixty-fourth-top (`setNamedDestXyz` / `parseNamedDestXyzInput` / `namedDestXyzFromPaper` / `namedDestXyzFromDestPage`), and dest names on thumbnails (`destNamesForPage`)) that can collapse or clear), page labels (1 / i, ii / Trang, or a selected prefix as i, ii then 1; shown on thumbnails; go to a label), extract embedded JPEG/PNG; open a password-protected PDF (working copy stays decrypted); download the result as PDF, optionally password-protected (working document stays readable). Reload in the same browser restores the last PDF and undo stack locally; the user can forget that copy.
- Convert: TXT, HTML, Markdown, RTF, JSON, JSONL, YAML, XML, CSV, TSV, TOML, Org, LaTeX, INI, AsciiDoc, RST, Textile, MediaWiki, DokuWiki, DocBook, OPML, Atom, Typst, Gemtext, POD, BBCode, Fountain, TiddlyWiki, Texinfo, roff, Jupyter, BibTeX, SRT, VTT, LRC, ICS, CUE, ASS, TTML, SBV, SAMI, SUB, STL, SCC, USF, RT, MPL, DjVu, PS, TEI, JATS, RIS, ENW, CSL-JSON, NBIB, CSL-YAML, EndNote XML, MODS, CFF, DataCite, MARCXML, Dublin Core, ONIX, Unixref, BibJSON, PubMed, JSON-LD, BIBFRAME, Crossref, EAD, METS, PREMIS, MIX, ALTO, PAGE, FOXML, EDM, LIDO, VRA, CDWA Lite, SPECTRUM, Darwin Core, Object ID, EAC-CPF, CIDOC CRM, METS Rights, TextMD, PBCore, EBUCore, MPEG-7, AES57, IEEE LOM, IMS CP, NewsML, NITF, SportsML, EventsML, NewsML-G2, rNews, PRISM, hNews, IPTC, ANPA, NINJS, JSON Feed, Activity Streams, GeoJSON, KML, GPX, XLSX, DOCX/DOC, ODT, ODS, PPTX, ODP, FB2, EPUB, MOBI, PNG, JPEG, WEBP, CBZ, optional page range with explicit empty/invalid-range errors, or the editor's multi-page selection (including non-contiguous pages). Opening TXT/Markdown/HTML/JSON/JSONL/YAML/XML/CSV/TSV/TOML/Org/LaTeX/INI/AsciiDoc/RST/Textile/MediaWiki/DokuWiki/DocBook/OPML/Atom/RSS/Typst/Gemtext/POD/BBCode/Fountain/TiddlyWiki/Texinfo/roff/Jupyter/BibTeX/SRT/VTT/LRC/ICS/CUE/ASS/TTML/SBV/SAMI/SUB/STL/SCC/USF/RT/MPL/DjVu/PS/TEI/JATS/RIS/ENW/CSL-JSON/NBIB/CSL-YAML/EndNote XML/MODS/CFF/DataCite/MARCXML/Dublin Core/ONIX/Unixref/BibJSON/PubMed/JSON-LD/BIBFRAME/Crossref/EAD/METS/PREMIS/MIX/ALTO/PAGE/FOXML/EDM/LIDO/VRA/CDWA Lite/SPECTRUM/Darwin Core/Object ID/EAC-CPF/CIDOC CRM/METS Rights/TextMD/PBCore/EBUCore/MPEG-7/AES57/IEEE LOM/IMS CP/NewsML/NITF/SportsML/EventsML/NewsML-G2/rNews/PRISM/hNews/IPTC/ANPA/NINJS/JSON Feed/Activity Streams/GeoJSON/KML/GPX/RTF, DOCX, ODT, ODS, XLSX, PPTX, ODP, FB2, EPUB, CBZ, or PNG/JPEG/WEBP builds a PDF first so those formats can round-trip.

## Out of scope for v1

- Accounts, cloud storage, OCR of scanned-only PDFs, collaborative editing.
