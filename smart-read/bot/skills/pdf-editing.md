# PDF editing

Operate on `PDFDocument` from `pdf-lib`. Never rewrite PDF bytes by hand.

## Supported operations

1. Rotate selected pages by 90° clockwise, 180°, or counterclockwise (`rotatePagesBy`; current page or multi-select). Reverse the whole document with `reversePages` and remap selection via `reversedIndexes`. Interleave two halves (duplex scan: fronts then backs) with `interleaveHalvesOrder` / `applyPageOrder`, or split odds then evens with `deinterleaveOddEvenOrder`. Remap the selection with `remapAfterOrder`. Pack selected (or all) pages onto 2-up / 4-up A4 sheets with `nUpPages` / `nUpCellRects`. Impose a saddle-stitch booklet with `imposeBooklet` / `bookletSlotOrder` (pad to a multiple of 4, 2-up landscape). Preview print sheets without mutating via `bookletPreviewSheets` / `bookletSlotLabel`. Flip selected pages with `flipPages` (horizontal or vertical). Split selected pages in half with `splitPagesInHalf` (`horizontal` = top then bottom, `vertical` = left then right) and remap via `remapAfterSplitHalf`; refuse if a half is smaller than `MIN_CROP_REMAINING`. Rotate selected pages to portrait or landscape with `orientPages` / `displayedPageSize` (square pages stay put). Scale selected pages with `scalePages` / `scaleFactor` (`SCALE_PERCENTS` 50/75/125/150; refuse below `MIN_CROP_REMAINING`).
2. Delete selected pages (keep at least one page). Odd/even select uses `oddPageIndexes` / `evenPageIndexes`. Invert the selection with `invertPageIndexes` (Ctrl+I). Select all with Ctrl+A. Stamp page numbers with `addPageNumbers` (`n`, `n-of-total`, `trang-n` at a footer/header preset). Stamp a watermark with `addWatermark` (`diagonal` / `footer` / `header`). Stamp a header and/or footer with `addHeaderFooter` (refuse if both are empty). Insert an A4 cover page at the start with `addCoverPage` (refuse an empty title). Stroke an inset border with `addPageBorder` / `borderBoxForPage` (same `CROP_MARGINS`; refuse a leftover box smaller than `MIN_CROP_REMAINING`). Crop selected pages with `cropPages` and `CROP_MARGINS` (`narrow` / `medium` / `wide`); `cropBoxAfterMargin` refuses a leftover box smaller than `MIN_CROP_REMAINING`. Add equal white margins with `padPages` / `paddedPageSize` (same `CROP_MARGINS`; refuse above `MAX_PADDED_SIDE`). Unify mixed selected pages onto one size with `unifyPageSizes` / `unifiedPageSize` (max width and height among the selection, content centered; need ≥2 pages; refuse above `MAX_PADDED_SIDE`). Overlay a reading tint with `tintPages` / `TINTS` (`cream` / `sepia` / `night`; empty `indexes` is refused). Paint an opaque page background with `colorPageBackgrounds` / `PAGE_BACKGROUNDS` (`cream` / `yellow` / `blue` / `gray`; embed onto a same-size colored sheet; empty `indexes` is refused; distinct from tint). Auto-crop whitespace with `autoCropPages` / `contentBoundsFromRgba` / `cropBoxFromContentBounds` (raster selected pages, crop to ink plus `AUTO_CROP_PADDING`; refuse if every selected page is blank or leftover is below `MIN_CROP_REMAINING`). Convert selected pages to grayscale with `grayscalePagePngs` + `replacePagesWithPngs` (flatten to an opaque PNG overlay; `grayscaleRgba` uses Rec. 709 luma). Find text with `findPagesWithText` / `foldSearch` (Vietnamese diacritics fold). Jump with `parseGotoPage` (1-based number, a viewer page label from `pageLabelsForCount`, or a dest name). `gotoSuggestions` fills the Tới trang datalist with labels then dest names. Remove pages whose extracted text is empty (`blankPageIndexes`); refuse if every page is empty (scanned/image PDF). Remove later pages whose folded text already appeared (`repeatedPageIndexes`); keep the first copy. Fit selected pages onto A4, Letter, or A5 with `fitPagesToPaper` / `PAPER_SIZES` / `fittedPageRect` (`fitPagesToA4` stays as the A4 wrapper; landscape pages use landscape paper).
3. Duplicate selected pages (`duplicatePages`) by inserting copies after the last selected index.
4. Extract selected pages (`extractPages`) as a separate PDF download without mutating the current document. Keep only the selection with `keepPages`. Split every N pages with `splitEvery` and download a ZIP (`zipPdfParts`). Split by top-level outline bookmarks with `splitByOutline` / `outlineSplitRanges` (pages before the first bookmark become `Trang đầu`; refuse when there is no outline). UI **Tách theo dấu trang**. Keep the selected outline item in the working document with `keepOutlineItem` / `outlineItemRange` (range runs until the next same-or-shallower item; nested children stay with the parent; refuse when no outline row is selected). UI **Giữ mục này**. Password-protect a download copy with `encryptPdfForDownload` / `assertPdfPassword` (refuse empty or mismatched confirm; the working document stays readable). Open a password-protected PDF with `decryptPdfForEdit` (working copy stays decrypted; empty or wrong password is refused). Add outline bookmarks for selected pages with `addOutlineBookmarks` / `listOutlineBookmarks` (refuse empty indexes or an empty title). Nest selected pages under a dest-less folder with `addOutlineFolder` (`depth` 0 parent + `depth` 1 children, or pass `parentIndex` for a nested folder up to `MAX_OUTLINE_DEPTH` 3; folders omit `/Dest`; `listOutlineBookmarks` walks First/Next and fills `pageIndex` from the first child). Collapse or expand one folder with `setOutlineFolderOpen`, or every folder with `setOutlineFoldersOpen` (negative `/Count` when closed; `visibleOutlineItems` hides children of a closed folder). Rename a row with `renameOutlineItem`. Move a sibling subtree with `moveOutlineItem`. Indent a row under the previous sibling with `indentOutlineItem` (refuse without a previous sibling or past `MAX_OUTLINE_DEPTH` 3). Outdent a row with `outdentOutlineItem` (the subtree is placed after remaining descendants of the parent; refuse a top-level row). Retarget a leaf with `setOutlineDest` (folders stay dest-less; an explicit page clears `destName`). Read catalog named destinations with `listNamedDests` (catalog `/Dests` and the `/Names` `/Dests` name tree, including `/Kids` leaves from other writers). Add a name for the current page with `addNamedDest` (refuse an empty/invalid name, a missing page, or a name already pointing elsewhere). Add unused `p{n}` names for selected pages with `addNamedDestsForSelection` / `namedDestNameForPage`. Rename with `renameNamedDest`, retarget with `setNamedDestPage` (the dest-row **Trang đích** input uses `parseNamedDestPageInput`, not the current viewer page), set XYZ/Fit/FitH/FitV/FitR/FitB/FitBH/FitBV with `setNamedDestView`, set XYZ left/top/zoom, A4/Letter/A5 top-left presets, and dest-page top/top-right/bottom-left/bottom/bottom-right/left/center/right edges and XYZ zoom 50%/75%/100%/125%/150%/200%/fit-width/fit-height/fit-page/keep/keep-left/keep-top/zero-left/zero-top/origin/home/max-left/max-top/far/end/mid/focus/mid-left/mid-top/quarter-left/quarter-top/three-quarter-left/three-quarter-top/eighth-left/eighth-top/sixteenth-left/sixteenth-top/thirty-second-left/thirty-second-top/sixty-fourth-left/sixty-fourth-top with `setNamedDestXyz` / `parseNamedDestXyzInput` / `namedDestXyzOf` / `namedDestXyzFromPaper` / `namedDestXyzFromPageSize` / `namedDestXyzFromDestPage` / `listPageSizes`, show dest names on thumbnails with `destNamesForPage`, remove with `removeNamedDest`, or clear every dest with `clearNamedDests` (outline leaves keep the page as an explicit dest). Writes go to catalog `/Dests` and the `/Names` `/Dests` name tree (`/Kids` when dests exceed `NAMED_DEST_LEAF_SIZE` or the source tree already has `/Kids`, including nested intermediate `/Kids` when leaves exceed the fanout). Point a leaf or folder at a name with `setOutlineNamedDest` (the name must already exist; folders keep `/Dest` as the name instead of the first child's page). Remove a row with `removeOutlineItem` (a folder is dropped and children move up one level). Remove the outline with `clearOutline` (refuse when empty). Set `/PageLabels` with `setPageLabels` (decimal / roman / Roman / Trang prefix) or `setFrontMatterPageLabels` when the selection is a document prefix (`frontMatterPageCount`). Show those labels on thumbnails via `pageLabelForIndex` / `pageLabelsForCount`, and dest names via `destNamesForPage`. Extract embedded JPEG (`DCTDecode`) and 8-bit RGB/Gray PNG XObjects with `extractEmbeddedImages` (download only; refuse empty indexes or no images).

6. Reorder pages (move up / down, drag a thumbnail, send a block to start/end, or Alt+↑↓). Dragging a selected thumbnail moves the whole selection as one contiguous block (`reorderPageBlock` / `movePages` / `blockEdgeDropTo`).
7. Undo / redo page operations (Ctrl+Z / Ctrl+Y); keep a bounded snapshot stack in IndexedDB (`persistHistory`, cap `MAX_PERSISTED_HISTORY`) so reload restores undo. Persist the current PDF in IndexedDB so reload restores the file. Offer **Xóa khỏi trình duyệt** to forget the local copy and history.
8. Merge another PDF at a chosen index (start, after current page, or end) using `insertPage`. Optionally add an outline bookmark covering the inserted pages with `mergePdfWithBookmark` / `mergeBookmarkTitle` (filename without `.pdf`). UI **Gắn dấu trang**.

## Implementation notes

- After every mutation, save the document and refresh page count + preview.
- Preview with dynamically imported `pdfjs-dist`; do not block the UI on the full file. Use `previewScaleForPage` so small/sparse pages render larger, and draw a thumbnail strip with `renderPageThumbnail` (higher contrast and scale on sparse pages).
- Merge copies pages with `copyPages` then `insertPage`.
- Text overlay uses `drawText`. Prefer an embedded Unicode font (`LiberationSans`) via `@pdf-lib/fontkit`; fall back to Helvetica.
- Keyboard: ArrowLeft/Right page, R rotate 90°, Shift+R rotate 180°, Delete remove, Alt+ArrowUp/Down reorder, Ctrl+Z undo, Ctrl+Y / Ctrl+Shift+Z redo, Ctrl+A select all, Ctrl+F focus search, Ctrl+G go to page, Ctrl+I invert selection, F3 / Shift+F3 next/previous hit (ignore when focus is in an input, except Ctrl+F/G/I still apply from the canvas).
- Download with a `Blob` of `application/pdf`.
